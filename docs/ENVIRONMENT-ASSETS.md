# 本轮环境资产来源登记（2026-09-08）

本轮未下载或新增第三方 GLB、GLTF、照片、HDRI 或岩石贴图，也未升级 Three.js r128。下表是全部新增程序资产。作者为 Codex 按本项目需求编写；来源就是表中的仓库源码，无外部原始下载链接。

这些资产属于本项目原创交付，未引入第三方素材授权依赖。仓库目前未声明整体对外分发许可证，本轮不擅自替项目指定 MIT、CC0 等公开许可证。已有室内模型和旧松针/树皮资产的来源声明保持原样，不重新授权。

## 第一轮动物 blocker 与当前状态

第一轮没有随该轮交付的、可核实授权与动画质量的近景动物 GLB。旧鱼、天鹅、兔子、狐狸以及 primitive 鸟类不再进入默认场景或拾取列表。远景生活感由原创行人图集承担，不能视为近景动物已完成。

> 2026-09-12 更新：该历史 blocker 已由 Rabbit 与 Fox 的许可模型部分解除。当前资产、作者、许可、文件、clip、压缩和校验和以 [春夏花卉与动画动物报告](FLORA-FAUNA-REFACTOR.md) 及 `room-preview/animal-manifest.js` 为准。随后按用户允许自建远景资产的要求，Swan 与 Fish 也已启用；当前为 3 兔、2 狐、5 天鹅、3 鱼及 9 只原创飞鸟。

当前模型来源、原创源码、许可、动画和性能以新版花卉动物报告为准。历史表中的 16 株春季图集花已由 FlowerSystem 的 288 株春花 / 198 株夏花替换；湖面新增几何高度波。后续近景动物细化计划见新版报告第 13 节。

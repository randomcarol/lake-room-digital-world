# 3D Room 的长期产品方向

## 结论：优先走 Hybrid

这个项目最有辨识度的形态不是“套着 3D 外壳的作品集”，也不是需要任务、战斗或经济系统的开放世界，而是一个**由个人经历驱动的 cozy interactive world**。房间始终是入口和视觉主体，外部世界按故事需要逐步生长；探索感服务于“认识这个人”，不反过来绑架内容。

## 方向一：Personal Homepage

- 适合求职、申请、作品展示与第一次访问。
- 首屏加载、清晰导航、简历和项目可读性优先；3D 负责建立记忆点。
- 建议保留一个随时可见的“快速了解我”入口，并为弱设备提供轻量模式。
- 优点是信息效率高、维护成本低；风险是房间容易退化成漂亮导航页。

## 方向二：Cozy Game

- 加入日夜、季节、动物作息、天气、随机来访和可收集记忆。
- 重点是陪伴感、停留时长和重复访问，而不是快速获取信息。
- 优点是世界感最强；风险是内容入口变深、制作和性能成本显著增加。
- 若尝试此方向，建议先做“小事件日历”，不要直接扩成无边界地图。

## 方向三：Hybrid（推荐）

- 房间：兴趣、阅读、音乐、照片和简历，是永远不变的核心。
- 世界地图：旅行故事与人生路径。
- 湖边：日记、心情和低干扰自然氛围。
- 记忆小镇：项目、朋友、重要经历和未来目标，每栋建筑只承载一类叙事。
- 动物：提供陪伴和微故事，不承担复杂任务系统。

建议按“一个区域 = 一类个人叙事 = 一个清晰交互样板”扩张。每次新增区域前先回答：它是否让访客更具体地了解我？如果答案是否定的，就暂时不做。

## 下一阶段样板：Travel Memory Map Demo

目标是在 60–90 秒内让访客完成一次有情绪、有信息量的个人故事探索。

1. 点击墙上世界地图，镜头平缓靠近，房间仍在边缘可感知。
2. 地图显示少量呼吸式图钉；选择图钉后围绕该点轻微放大。
3. 右侧滑出一张有纸张、邮戳和照片质感的明信片。
4. 明信片展示地点、日期、一张主照片、短句和一段个人故事。
5. 左右按钮切换地点；地图焦点同步移动，形成“翻旅行手账”的节奏。
6. 关闭后镜头回到原房间位置，不打断继续探索。

当前迭代已经实现这条体验链的前端 MVP，并在 Owner Studio 中提供自定义地图、旅行字段和拖动图钉坐标。下一步最值得投入的是：多图排序、手账式长故事分页、图钉聚类，以及一组经过真实内容编辑的 3–5 个地点样本。

## 内容与世界扩展原则

- 先真实内容，后扩大地图；三个讲得好的故事胜过三十个空图钉。
- 动效要可跳过、可降级，并尊重 `prefers-reduced-motion`。
- 音频默认静音；未来环境声使用连续、低动态的水流与风声，不使用突然触发的鸟叫。
- 保持 `environment / seasonal system / animal system / interaction system / content schema` 分离，让每一层都能独立替换。

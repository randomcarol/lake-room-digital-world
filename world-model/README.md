# World Simulation Lab

这是 Lake Room 的第一版世界模拟基础设施，入口为 `world-model/demo.html`。它是**确定性的多角色规则模拟器**，不是训练出的世界模型，也没有调用大语言模型。

## 当前实现

- 带种子的伪随机数：同一个场景和种子会产生相同状态与事件，便于回归测试。
- 受限观察：角色只能看到自己的状态、当前地点、相邻地点和同地点角色。
- 受限动作：`rest / explore / forage / socialize / observe`。
- 有界状态：精力、社交和好奇心始终位于 `0–1`。
- 追加式事件：动作、人物模板语言、动物非语言信号、相遇故事节点与策略拒绝均进入事件流。
- 安全策略接口：外部策略只能提出动作；无效、越界或抛错的提议会被拒绝并退回规则策略。
- 物种边界：动物不会生成或发出人类对白。

当前事件只存在浏览器内存中，刷新即重置；实验室不会读写正式 3D 房间世界存档，也不会自主调用外部工具。

## 文件边界

- `scenario.json`：可读的地点图、角色初始状态和性格参数。
- `schema.json`：场景数据的 JSON Schema。
- `simulation.js`：无 DOM 依赖的可信模拟内核，可在浏览器和 Node 中运行。
- `demo.html / demo.css / demo.js`：只读可视化实验室与手动推进控制。
- `tests/world-simulation.cjs`：确定性、状态边界、物种语言边界和不可信策略测试。

## 推荐演进顺序

1. **确定性内核与评估**（当前）：让状态、动作、事件和错误都可重放、可测试。
2. **只读房间观察适配器**：把季节、时间和公开地点映射给实验室，仍不允许模拟器写正式世界。
3. **模型策略实验**：模型基于受限观察提出结构化动作，不直接改变状态。
4. **服务端验证与审计**：校验权限、频率、目标和资源预算，保存可追踪事件。
5. **显式选择接入正式世界**：先灰度到一个人物和一类事件，再根据稳定性扩大。

在进入第 3 步前，应先定义离线评估集：非法动作率、重复对白率、角色一致性、物种边界、事件多样性和单次模拟成本。没有这些指标，接入模型只会让演示更随机，不会让世界更可信。

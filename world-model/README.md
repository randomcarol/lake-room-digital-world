# World Simulation Lab

这是 Lake Room 的世界模拟基础设施，入口为 `world-model/demo.html`。它是**确定性的多角色规则模拟器**，不是训练出的世界模型，也没有调用大语言模型。

## 当前实现

- 带种子的伪随机数：同一个场景和种子会产生相同状态与事件，便于回归测试。
- 受限观察：角色只能看到自己的状态、当前地点、相邻地点和同地点角色。
- 受限动作：`rest / explore / forage / socialize / observe`。
- 有界状态：精力、社交和好奇心始终位于 `0–1`。
- 追加式事件：动作、人物模板语言、动物非语言信号、相遇故事节点与策略拒绝均进入事件流。
- 安全策略接口：外部策略只能提出动作；无效、越界或抛错的提议会被拒绝并退回规则策略。
- 物种边界：动物不会生成或发出人类对白。
- 只读房间观察：读取同源浏览器内最近 5 分钟的季节、时间和公开地点白名单，异常或过期时使用内置场景。
- 离线评估：固定种子双重重放，分别报告安全门槛和质量目标，不以降低目标掩盖当前缺口。

当前事件只存在浏览器内存中，刷新即重置；实验室不会写入正式 3D 房间世界存档，也不会自主调用外部工具。观察快照只保存在浏览器同源 `localStorage`，不包含相机、精确坐标、个人内容、后台数据或凭据。

## 文件边界

- `scenario.json`：可读的地点图、角色初始状态和性格参数。
- `schema.json`：场景数据的 JSON Schema。
- `simulation.js`：无 DOM 依赖的可信模拟内核，可在浏览器和 Node 中运行。
- `room-observation.js`：环境状态裁剪、严格校验、时效检查和场景适配；不包含网络或世界写入接口。
- `evaluation.js`：纯计算评估器；统计重放、语义、状态、物种、策略、覆盖、重复度和成本指标。
- `evaluation-schema.json`：版本化评估报告协议。
- `evaluation-baseline.json`：由当前场景和评估器确定性产生的版本化基线。
- `generate-evaluation.cjs`：场景或评估器改变后重新生成基线的唯一入口。
- `evaluation.html / evaluation.css / evaluation-view.js`：面向人的桌面与移动端评估报告。
- `demo.html / demo.css / demo.js`：只读可视化实验室与手动推进控制。
- `tests/world-simulation.cjs`：确定性、状态边界、物种语言边界和不可信策略测试。
- `tests/world-observation.cjs`：观察协议、字段白名单、过期回退和不可变适配测试。
- `tests/world-evaluation.cjs`：报告可重复性、提交基线一致性、安全门槛和失效策略测试。
- `tests/world-simulation-browser.cjs`：房间到实验室的真实跨页面单向数据流和桌面/移动端验收。

## 当前基线

- 10 个固定种子 × 64 步 × 3 个角色。
- 1,920 次角色决策，3,769 个事件。
- 不可重放、事件语义违规、状态越界、动物人类对白和未知事件均为 0。
- 动作、地点、核心事件类型和角色表达边界覆盖均通过。
- 对白唯一率为 8.3%，低于 25% 的质量目标；因此总体状态是 `pass-with-quality-gaps`，不是完全通过。

修改场景、模拟器或评估器后运行 `node world-model/generate-evaluation.cjs` 更新基线，再运行 `node tests/world-evaluation.cjs`。后一个命令会拒绝未同步的报告和任何安全门槛回归。

## 推荐演进顺序

1. **确定性内核与评估**（已完成）：让状态、动作、事件和错误都可重放、可测试。
2. **只读房间观察适配器**（已完成）：把季节、时间和公开地点映射给实验室，仍不允许模拟器写正式世界。
3. **离线评估基线**（已完成）：量化非法动作、重复对白、角色一致性、物种边界、覆盖度和成本。
4. **提升规则表达基线**（下一步）：把人物对白唯一率提高到至少 25%，动物仍只保留非语言信号。
5. **模型策略对照实验**：模型基于受限观察提出结构化动作，与规则基线使用同一评估器比较。
6. **服务端验证与审计**：校验权限、频率、目标和资源预算，保存可追踪事件。
7. **显式选择接入正式世界**：先灰度到一个人物和一类事件，再根据稳定性扩大。

在进入第 5 步前，先让规则基线达到既定质量目标。否则模型即使比当前结果好，也可能只是超过了一个过弱的对照组，不能证明它值得承担延迟、成本和不可预测性。
